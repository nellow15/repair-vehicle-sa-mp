# Vehicle Repair System (MoonLoader)

Simple Vehicle Repair System untuk SA:MP menggunakan MoonLoader dengan
ImGui menu. Repair kendaraan bisa menggunakan tombol 0 atau command
/kitveh.

------------------------------------------------------------------------

## Author

-   Script Author: ShardoX
-   Edited / Published by: NelloW15
-   Version: 2.0

------------------------------------------------------------------------

## Fitur

-   Repair kendaraan dengan tombol 0
-   Command /kitveh
-   Menu pengaturan dengan /repairmenu
-   Cooldown 10 detik setiap repair
-   Cooldown bar di layar
-   Bisa mengaktifkan / menonaktifkan fitur repair

------------------------------------------------------------------------

## Requirements

Pastikan sudah menginstall:

-   MoonLoader

------------------------------------------------------------------------

## Cara Install

1.  Download file script ini.
2.  Masukkan file `.lua` ke folder:

GTA San Andreas/moonloader/

3.  Jalankan GTA SA dan masuk ke server SA:MP.
4.  Jika berhasil, akan muncul notifikasi di chat bahwa script sudah
    loaded.

------------------------------------------------------------------------

## Cara Penggunaan

### Repair Kendaraan

-   Masuk ke dalam kendaraan.
-   Tekan tombol 0 (angka nol).

Atau gunakan command: /kitveh

### Menu Pengaturan

Untuk membuka menu: /repairmenu

Di dalam menu kamu bisa: - Mengaktifkan / menonaktifkan fitur repair -
Melihat status cooldown - Melihat panduan penggunaan

------------------------------------------------------------------------

## Cooldown

-   Setiap repair memiliki cooldown 10 detik.
-   Cooldown bar akan muncul di pojok kanan bawah layar.
-   Tidak bisa repair jika cooldown belum selesai.

------------------------------------------------------------------------

## Catatan

-   Kamu harus berada di dalam kendaraan untuk menggunakan repair.
-   Fitur tidak akan bekerja jika sedang mengetik di chat atau dialog
    terbuka.
-   Script ini berjalan di sisi client (MoonLoader).
